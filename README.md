# java-blackjack

블랙잭 미션 저장소

# ✅ 구현할 기능 목록

## 게임 준비

---

### 참여자 이름 입력받기

- [ ]  게임에 참여할 플레이어의 이름 입력받기
    - [ ]  안내 메시지: `게임에 참여할 사람의 입력을 입력하세요.`
    - [ ]  입력 형태: `pobi,jason`

### 입력값 기본 파싱 및 검증

- [ ]  입력의 앞뒤 공백 제거하기 (trim)
- [ ]  입력이 공백인 경우 재입력
    - [ ]  예외 메시지: `[ERROR] 입력값이 비어있거나 공백입니다.`

### 플레이어 이름 파싱

- [ ]  `,` 기준으로 이름을 나누기
    - [ ]  이름 사이 공백 허용하고 이를 제거함

### 플레이어 이름 객체 생성 및 검증

- [ ]  이름이 공백일 경우 재입력
    - [ ]  예외 메시지: `[ERROR] 이름은 공백이 될 수 없습니다.`
- [ ]  이름 길이가 10글자가 넘을 경우 재입력
    - [ ]  예외 메시지: `[ERROR] 이름 길이는 최대 10글자입니다.`

### 전체 플레이어 명단 검증
- [ ]  중복되는 이름이 있을 경우 재입력
    - [ ]  예외 메시지: `[ERROR] 중복되는 이름이 존재합니다.`

### 플레이어 당 배팅 금액 입력
- [ ] 배팅 금액 입력
    - [ ]  안내 메시지: `pobi의 배팅 금액은?`
    - [ ]  입력 형태: `20000`
    - 
### 입력값 기본 파싱 및 검증
- [ ]  입력의 앞뒤 공백 제거하기 (trim)
- [ ]  입력이 공백인 경우 재입력
    - [ ]  예외 메시지: `[ERROR] 입력값이 비어있거나 공백입니다.`

### 배팅 금액 객체 생성 및 검증
- [ ] 배팅 값이 숫자가 아닌 경우 재입력
  - [ ] 예외 메시지: `[ERROR] 배팅 금액은 숫자이어야 합니다.`
- [ ] 배팅 값이 음수일 경우 재입력
  - [ ] 예외 메시지: `[ERROR] 배팅 금액은 음수를 입력할 수 없습니다.`

## 게임 초기 진행

---

### 덱 섞기
- [ ]  게임 시작과 동시에 카드 섞기
    - [ ]  52장의 카드

### 초기 카드 분배

- [ ]  게임 시작 시 모든 사람에게 2장씩 주기
    - [ ]  딜러와 모든 플레이어에게 전달
    - [ ]  딜러 > 플레이어 이름 입력 순으로 전달

### 초기 카드 정보 출력

- [ ]  초기 카드 배분 결과 출력하기
    - [ ]  출력 형태: `딜러와 {player1}, {player2}에게 2장을 나누었습니다.`
    - [ ]  딜러는 1장의 카드 정보만 출력
        - [ ]  출력 형태 예: `딜러카드: 3다이아몬드`
    - [ ]  플레이어는 2장의 카드 모두 출력
        - [ ]  출력 형태 예: `pobi카드: 2하트, 8스페이드, A클로버`

---

### 카드 추가 수령 여부 입력

- [ ]  플레이어에게 카드 추가 수령 여부 입력받기
    - [ ]  안내 메시지: `{playerName}는 한장의 카드를 더 받겠습니까?(예는 y, 아니오는 n)`
    - [ ]  입력 형태: `y` 혹은 `n`
- [ ]  입력값 기본 검증 거치기
- [ ]  y, n이 아닌 경우 재입력
    - [ ]  예외 메시지: `[ERROR] y 혹은 n으로 입력해야 합니다.`

### 카드 지급 및 누적 카드 정보 출력

- [ ]  `y`를 입력한 경우, 카드 1장을 추가로 지급하기
- [ ]  현재 해당 플레이어의 카드 목록 출력하기
    - [ ]  출력 형태 예: `pobi카드: 2하트, 8스페이드, A클로버`

### 버스트 판별

- [ ]  누적 카드 합계 계산하기
- [ ]  21점 초과일 경우, 버스트로 판단하기

### 카드 추가 수령 종료 조건 판별

- [ ]  다음 조건 중 하나일때까지 반복하기
    - [ ]  `n`를 입력할때
    - [ ]  버스트가 될때
    - [ ] 블랙잭일 때

## 딜러의 카드 추가 수령

---

### 딜러 카드 수령 조건 판별

- [ ]  누적 카드 합계 계산하기
- [ ]  누적 카드 합계가 16이하이면, 추가 카드 받기
    - [ ]  안내 메시지: `딜러는 16이하라 한장의 카드를 더 받았습니다.`
- [ ]  누적 카드 합계가 17 이상이면, 딜러의 추가 카드 수령 종료

## 게임 결과

---

### 최종 점수 계산

- [ ]  참여자의 카드 합계 계산
    - [ ]  Ace는 11로 디폴트, 21점 초과시 1로 계산

### 참여자의 최종 카드 및 결과 출력

- [ ]  각 참여자의 카드 목록과 최종 점수 출력
    - [ ]  출력 형태 예: `딜러카드: 3다이아몬드, 9클로버, 8다이아몬드 - 결과: 20`

### 플레이어들과 딜러 승패계산
- [ ] 플레이어가 버스트인 경우 → 플레이어 패
- [ ] 플레이어와 딜러 모두 블랙잭인 경우 → 무승부
- [ ] 플레이어만 블랙잭인 경우 → 플레이어 승 (1.5배)
- [ ] 딜러만 블랙잭인 경우 → 플레이어 패
- [ ] 딜러가 버스트인 경우 → 플레이어 승
- [ ] 플레이어 점수가 딜러보다 높은 경우 → 플레이어 승
- [ ] 딜러 점수가 플레이어보다 높은 경우 → 플레이어 패
- [ ] 점수가 같은 경우 → 무승부

### 최종 수익 출력

### 최종 수익 출력

- [ ] 딜러와 모든 플레이어의 승패를 비교한다.
- [ ] 플레이어 승 → 배팅 금액만큼 +, 딜러는 그만큼 -
- [ ] 플레이어 블랙잭 승 → 배팅 금액의 1.5배 +, 딜러는 그만큼 -
- [ ] 플레이어 패 → 배팅 금액만큼 -, 딜러는 그만큼 +
- [ ] 무승부 → 수익 0
- [ ] 딜러의 최종 수익은 모든 플레이어 수익 합계의 반대이다.
